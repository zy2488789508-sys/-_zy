### 1. 启动步骤
因为未将传感器的驱动编译进内核，所以在系统开启时需要手动将驱动模块挂载在/lib/modules/4.1.15-ge48931b1目录下，挂载完成后,执行./dual_sensor,便可以同时采集MAX30102，BMP280，MPU6500，ATGM33H的数据，然后执行Qt软件，读取共享内存中的数据，并显示在屏幕中。

### 2. 本地传感器融合与可视化
- **多源数据采集**：C语言多线程同时读取 MPU6500 陀螺仪/加速度计、GPS、MAX30102 心率血氧及 BMP280 气压温度传感器。
- **算法处理**：将 GPS 原始速度通过**卡尔曼滤波**算法进行噪声过滤，输出平滑的实时速度；基于加速度计设计**二段式状态机**进行跌倒检测。
- **Qt界面展示**：上位机界面实时更新所有传感器标签，利用 `QtCharts` 模块绘制**心率与速度的动态折线图**，利用 `QPainter` 模块绘制**GPS轨迹点连动图**。

### 3. MQTT 远程数据上报与报警通知
- **通信协议**：底层代码集成 **MQTT 物联网协议**，连接到远程主机服务器。
- **定时上报数据**：以 **5秒** 为一个周期，将处理后的 **GPS经纬度** 和 **卡尔曼滤波后的平滑速度 (km/h)** 发布（Publish）到远程 MQTT 服务器，实现长期远程定位监控。
- **跌倒双向通知机制**：
- **本地报警**：检测到跌倒时，Qt 上位机立即弹出“紧急报警”弹窗。
- **远程推送**：同时通过 MQTT 向远程主机推送 **跌倒报警标志位**，主机服务端可收到报警通知。
- **远程指令反馈**：支持远程主机通过 MQTT **下发消息指令**给开发板设备，实现软硬件的双向控制闭环。
